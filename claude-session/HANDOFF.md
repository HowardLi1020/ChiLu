## 這是什麼

一個純 HTML / CSS / JS 的「手作日記相簿」網頁，要送給喜歡的對象（彼此知道心意、還沒在一起；**不是告白**，只是想跟對方說一些話）。
最後會放上網路、做成 **QR code 讓對方用手機掃描觀看**，所以**一切以手機直向畫面為準**。

## 使用者的偏好與決定（重要）

- **手機優先**：所有版面、互動都以手機直向為準。
- **配色**：溫暖的鵝黃色、淡奶油色為主；紙張、牛皮紙、紙膠帶等手作質感。
- **花栗鼠元素已全部拿掉**（使用者要求），不要再加回去。
- **不是告白**：最後一頁是「結語」，沒有任何「答應／想想」之類的按鈕。
- **整本是翻頁的日記相簿**：一頁一頁像手作剪貼卡片，手指左右滑翻頁。
- **照片一律完整顯示、不裁切**；只有為了黏貼感被其他照片疊住是可以接受的。
- **照片背面可以寫一段話**：有寫的照片會出現「翻過來看 ↻」提示，點了翻面。
- **撿橡果小遊戲已拿掉**；「關於妳」那頁保留，改成兩張一排的小卡。
- **對她一律用「妳」**，不要用「你」（使用者要求全部統一）。封面英文「FOR YOU」保留。
- **底部按鈕列（上一頁／頁數／下一頁）已拿掉**，只用手指左右滑翻頁；音樂按鈕縮成右下角半透明小圓。
- **必須適應 4.7 吋（iPhone SE，375×667，扣掉 Safari 工具列約 375×553）、6.3 吋（402×874）、6.9 吋（440×956）**，改版面後要在這幾種尺寸都檢查，不能只看一種。
- 使用者給照片小字時用空格分句，放進 data.js 時改成全形逗號（或冒號）。
- **封面是一張明信片（寫字的那一面）**：印刷抬頭（原本是 POST CARD，使用者改成「FOR YOU／寫給妳的日記」）、齒孔郵票（向日葵；`coverPhoto` 有填就用那張照片當郵票圖案）、圓形郵戳、左下角落款「DIARY · 2026」（原本 HANDMADE DIARY）、深藍黑手寫字（`heroTitle`、`heroSub`、`to`），右側貼一張小照片（`postcardPhoto`，目前是 `images/IMG_4616.jpg` 早餐店的蛋餅、吐司和飲料；之前用過 `IMG_7067` 兩人並肩走在街上的背影）。使用者覺得用 CSS 畫相簿等立體物品看起來假又廉價，**平面的紙類物品（明信片、便條、信紙）比較真實**，之後設計請朝這個方向。

## 檔案結構

```
index.html            頁面骨架（相簿、音樂按鈕、燈箱、向日葵 SVG）；CSS/JS 網址帶 ?v=版本號
style.css             全部樣式（紙張、封面、紙膠帶、相角、印章、日記橫線、照片翻面⋯）
script.js             產生每一頁、翻頁（拖曳／鍵盤）、照片排版、燈箱、音樂
data.js               ★ 所有文字內容都在這裡改（前言、每趟日記、照片背面的話、結語）
images/               壓縮後的照片（網頁實際使用）
  <資料夾>/*.jpg      1600px 大圖（燈箱用）
  <資料夾>/m/*.jpg    1000px（照片頁用）
  <資料夾>/s/*.jpg    480px 縮圖
  sizes.js            每張照片的原始寬高（自動產生，排版不裁切要用）
tools/compress_photos.py  把 photos/ 原圖壓縮成 images/（並移除 GPS、產生 sizes.js）
tools/screenshot.py       無伺服器的手機寬度截圖工具（給 Claude 檢查畫面用）
photos/               原圖（含拍攝地點 GPS；**不進 git**，已列入 .gitignore，只留在本機）
music/                想改用 mp3 時放 song.mp3（目前用 YouTube）
claude-session/       這份交接文件與對話紀錄
```

## data.js 結構

```js
to, heroTitle, heroSub, postcardPhoto, coverPhoto   // 封面（明信片）
music: { youtube, start, volume }
preface:  { title: "前言", text: "", photo, caption }   // photo＝文字底下貼的拍立得，caption＝下緣手寫小字
trips: [{
  date, dot,
  title: "",        // 這趟的標題
  diary: "",        // 這趟的日記（太長會自動可以在那頁往下捲）
  diaryPhoto, diaryCaption,   // 可不填：日記底下貼的拍立得與下緣小字（一張用字串，多張並排用陣列）
  pageNotes: [],              // 可不填：照片頁空白處的手寫字（依頁序）；placeNotes() 自動找離照片最遠的空白，放不下一行時分兩行（可用 \n 指定）
  photos: [{ src: "images/.../IMG_xxxx.jpg", note: "", caption: "" }]   // note 有字 → 可翻面；caption → 拍立得下緣加寬、寫兩行手寫小字；whole: true → 這頁照片一起縮小到不會蓋住這張（有人像時用）
}]
traits: [{ icon, word, back }]       // 關於妳小卡，兩張一排、張數不限；back 有字的才能翻面（目前 6 張、都沒寫背面）
epilogue: { title: "結語", text, photo, caption, bigLast: true, sign: "" }   // text 裡單獨一行寫 [照片] = 在那裡浮現 photo（目前 IMG_7067）
```

已填：封面文字、前言、10 趟日記、日記頁照片、大部分照片小字、關於妳 6 張小卡、結語（文字＋照片）。還空著：各趟標題、照片背面的話（note）、小卡背面、結語落款（sign）、結語照片的小字。照片順序 = 照片頁上的貼法順序。

## 技術重點（改程式前先知道）

- **翻頁**：每頁是 `.page`（正面 `.face.front` 放內容、背面 `.face.back` 空白），以左邊為軸 `rotateY(0 → -180deg)`。`layout()` 管疊放順序與可見範圍。
- **iPhone 捲不動的修正**：停在眼前的那一頁加 `.flat`（拿掉 3D、`transform: none`），翻頁開始時才移除。iPhone Safari 在 3D 頁面裡手指捲不動。
- **記憶體（iPhone 會把分頁砍掉重載、跳回封面）**：只畫目前頁 ±2（其他 `display: none`），±1 才 `visibility: visible`；圖片載入到 +3 頁（`hydrate`），離目前頁 3～5 頁以上的照片放掉（`dehydrate`）。`.page` 不要加 `will-change`。
- **網址記住頁數**：`#p=頁數`，重新載入會回到那一頁。
- **拖曳翻頁**：水平拖曳才翻頁，垂直交給頁面捲動（日記頁可捲）。拖曳後會擋掉那次 click。
- **照片頁排版**：`LAYOUTS` 定義每張照片的區塊與貼齊角落，`placeSnaps()` 依 `images/sizes.js` 的比例把整張照片縮放進區塊（不裁切）；版型會左右鏡像交替。視窗大小改變、字型載入完成都會重排。
  - 拍立得小字字級 = 頁寬 × `CAP_FS`（約 15～17px），在畫面外的 `.snap-cap-measure` 實際排一次量高度（`capTextH`），再決定下緣白邊多高。放不下時字縮到 90／80／72%，照片最窄保留頁寬 42%；照片一律夾在頁面內。
  - 區塊放太大會讓照片超出頁面、蓋住塗鴉（試過，使用者覺得很醜），目前區塊寬約 72～82%。
- **照片翻面**：`.snap.has-note` → `.snap-inner` 旋轉，背面 `.snap-back` 是橫線便條紙。
- **日記頁**：`.diary .sheet` 的橫線用 `background-attachment: local` 跟著文字捲動，行高 34px 對齊橫線。
- **結語**：翻到時 `epilogue.text` 依 `\n` 一行一行浮現、遇到 `[照片]` 浮現拍立得，新的一行超出畫面會自動慢慢往下捲，最後一行放大（使用者要求：結尾**不要**有飄落 emoji 的特效）。
- **iPhone 注意**：之前遇過信封開場在結尾同時「縮放＋淡出＋移除」時閃到左上角，所以避免在同一個元素上同時做這些。

## 手機上看（區網）

使用者同意後才能開：`python -m http.server 8000 --bind 0.0.0.0`，手機連同一個 Wi-Fi 開 `http://<電腦 IP>:8000`。用完要關掉。
**改了 CSS/JS/data.js 之後，要把 index.html 裡四個 `?v=數字` 一起加 1**，不然手機會一直用快取的舊檔。

## 常用指令

```bash
# 新增／替換照片後（放進 photos/ 或它的子資料夾再執行；只會處理有變動的照片）
python tools/compress_photos.py

# 手機寬度截圖（不開伺服器），例如看第 1、2、3 頁，以及第 3 頁把有字的照片翻面
python tools/screenshot.py 1 2 3 3f
python tools/screenshot.py --demo 1 2 3f    # 塞示範文字（只在測試頁，不改 data.js）

# 更新對話紀錄：在 Claude Code 匯出對話（session 選單的 Export）後
python tools/transcript_to_md.py <匯出的 zip>
```

截圖存在 `tools/_shots/`（不進 git）。需要電腦上有 Chrome 或 Edge。
兩支腳本都需要 Python 和 Pillow（新電腦先執行 `python -m pip install --user pillow`）。
